## [Unreleased]

### Added
- **GitHub Marketplace billing webhook** (agentops-015, 73d3a1c → ba974a1) — `POST /webhook/github-marketplace` reads the raw request body (1 MiB cap), verifies `X-Hub-Signature-256` against `GITHUB_WEBHOOK_SECRET` via constant-time HMAC-SHA256, and logs one structured line per accepted `marketplace_purchase` action. The five recognised actions are `purchased`, `cancelled`, `changed`, `pending_change`, and `pending_change_cancelled`; any other action returns `422` so misconfigurations surface loudly. Missing `GITHUB_WEBHOOK_SECRET` fails loud with `500`. Ships as a stdlib-only Cloud Run image via `Dockerfile.webhook`, exposing `GET /health` for liveness probes. Mirrors the Guardian billing webhook (agentops-014) exactly — the GitHub Marketplace event format is shared across both listings. Ping deliveries are now acknowledged with `200` (ba974a1) so GitHub stops retrying the handshake.
- **Pulse app test coverage 49.4% to 62.5%** (agentops-051, 38729c8, PR #2) — five focused test files target the lowest-covered pure-function paths: `internal/analyzer/ignore_test.go` raises `loadPulseignore` 29.4% to 94.1% and `matchesIgnorePattern` 0% to 100%; `internal/git/git_test.go` brings the package to 95.8% by covering all nine exported funcs (`Log`, `Checkout`, `CurrentRef`, `CurrentBranch`, `MergeBase`, `Stash`, `StashPop`, `IsDirty`) plus `itoa` against hermetic temp git repos; `internal/complexity/dispatch_test.go` raises `AnalyzeFile` 71.4% to 100%; `internal/complexity/golang_extra_test.go` covers `receiverName`, `cognitiveStmt`, and `cyclomaticGo` corners; `internal/report/report_test.go` brings `gradeColor`, `shortPath`, `fmtNum`, and `printDelta` from 0% to 100%. 77 tests to 122 tests, all green. Stdlib only, no production code changes.
- **`cmd/pulse` command handler coverage 0% to 87.7%** (agentops-056, 20c143d, PR #3) — `cmd/pulse/main.go` refactored to extract `newRootCmd` (cobra root setup leaves `main()` for `os.Exit`) plus a package-level `exitFunc` seam routing the gate-failure exit so `gateCmd` can be tested without terminating the test binary. `main_test.go` then covers all eight previously-0% handlers: `shortPath` 100%, `checkGates` 100%, `computeDiff` 100%, `checkCmd` 94.4%, `gateCmd` 96.0%, `trendCmd` 77.5%, `diffCmd` 77.8%, and `newRootCmd` 100%. Test-fixture pattern reuses `initRepo` from `internal/git/git_test.go` and the temp-dir + `WriteFile` style from `internal/analyzer/analyzer_test.go`; the `exitFunc` swap follows the Guardian pattern from agentops-053 (PR #6 5d85fae). 147 tests passing, up from 122. No behaviour change at runtime.
- **`cmd/webhook` command coverage 0% to 68.4%** (agentops-059, c79a581 + 638c632, PR #5) — `cmd/webhook/main.go` refactored to extract four pure seams so the wiring is testable without binding to a port: `resolvePort` (env defaulting to 8080), `newServer` (mux + `*http.Server` with `ReadHeaderTimeout`), `serve` (`ListenAndServe` wrapper that treats `http.ErrServerClosed` as nil), and `logStartup` (boot-time log lines including the missing-secret warning). `main()` reduces from 18 statements to 6 (env reads + glue). `main_test.go` then covers every seam at 100%: `resolvePort` both branches, `newServer` Addr/`ReadHeaderTimeout`/Handler wiring plus `GET /health` 200, signed `POST /webhook` 200, and wrong-method 405, `serve` graceful-Close and bind-failure paths, and `logStartup` warn/silent/listening lines. `main()` itself stays 0% (unreachable from tests by definition; only 6 glue statements remain). `cmd/webhook` package coverage 64.6% to 85.9%; 36 tests in the package (was 25); 158 tests passing overall (was 147). Reuses `testSecret` + `sign()` from `handler_test.go` and the `bytes.Buffer` + `log.SetOutput` capture pattern shared with the Cerebra and Guardian webhook tests; extraction pattern mirrors agentops-056 (`cmd/pulse`) and agentops-053 (Guardian). Stdlib only, no new dependencies, no behaviour change at runtime.
